# Domivio

O Domivio é um aplicativo mobile desenvolvido para facilitar a compra e venda de imóveis de forma direta, sem intermediários.

Neste app, o usuário pode se registrar como comprador ou vendedor, fazer login, criar anúncios de imóveis (para vendedores), listar e favoritar posts localmente, além de conversar via chat com outros usuários.

---

> **Tecnologias utilizadas**
>
> - React Native  
> - Axios  
> - AsyncStorage  
> - Expo  
> - JavaScript  

---

## Funcionalidades

- Cadastro e login de usuários  
- Criação e listagem de imóveis  
- Favoritação local de anúncios  
- Chat entre comprador e vendedor  
- Comunicação com a API REST via Axios  

---
